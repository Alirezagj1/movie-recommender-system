Movie Recommender System

An end-to-end machine learning project for building a movie recommendation system using Python, SQL Server, Machine Learning, and Git/GitHub.

Project Overview

The goal of this project is to develop a recommendation system that can suggest relevant movies to users based on movie characteristics and user preferences.

The project covers the complete workflow from data exploration and preprocessing to SQL-based data management, recommendation modeling, evaluation, and generating personalized movie recommendations.

Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- SQL Server
- SQLAlchemy
- PyODBC
- Jupyter Notebook
